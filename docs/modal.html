语言与研究边界

O(p)：应当 p。P(p)：弱许可（未被禁止），定义为 !O(!p)，不等于法规明示授权。F(p)：禁止 p，定义为 O(!p)。

连接词：! 否定、& 合取、| 析取、-> 蕴含、<-> 等价。可使用中文命题名、true/false、括号及嵌套。

优先级：否定与模态 → 合取 → 析取 → 蕴含 → 等价。蕴含向右结合。O、P、F 是保留符号；本版本没有主体参数、量词或二元条件义务算子。

每个世界至少有一个可达世界；不要求自身可达。因此，应当成立不保证实际发生。未提供事实不是提供了该事实的否定；这里没有 K3 的第三真值。

本研究台独立于劳动争议规则评估。算例是形式化示意，不会自动把现有34条规则翻译成模态公理。资源上限触发时返回“未判定”。

如何核查结果

闭合表证书逐步检查布尔展开和模态见证；反模型逐世界检查串行性及公式真值。检查模块不调用求解器，但共享公式解析与规范化模块。结果不证明现实证据真实或法律规范有效。
