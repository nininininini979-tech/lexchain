# LexChain 律链

LexChain 面向遇到劳动争议的劳动者，默认提供「工人求助」流程：选择问题、填写事实、核对证据、查看初步意见。优先支持欠薪月份整理与工资差额小计，保留专业事实面板和可审计的规则推演。

## GitHub Pages

公开页面：`https://nininininini979-tech.github.io/lexchain/`

Pages 版本直接加载 `docs/rules/labor-rules.json`，在浏览器内计算。求助模式只使用用户明确回答的选项和金额，不从自由描述猜测事实，不上传案件内容或文件。空白金额保持未知；不完整月份不计入小计；重复月份会拦截。刷新页面会清空本次资料，目前不提供案件存储或自动提交。

工人求助与专业审阅共享案件事实。专业面板修正后，返回求助模式会重新计算；有争议或未知的事实仍需人工核对。公开版已取消容易误判的关键词抽取，请使用事实面板；本地专业模式仍支持已配置的 DeepSeek/Ollama，点击文本分析前页面会说明发送范围。

意见区区分已匹配法条与条件未确认的相关条文，展示证据缺口、可能的其他解释与求助路径。适用范围为中国大陆劳动争议，当前规则库 v0.5.1（34 条规则）；地方规定、最新裁审口径及法规整体有效性尚未经人工法律复核。工伤及其他争议仅作材料整理和人工转介。

本版只估算工资差额，不自动计算加班费、二倍工资差额、经济补偿、赔偿金或工伤赔付，不保证案件结果。金额还需核对税前/税后口径、合法代扣、到账及应付日期。

## 本地运行

```bash
node server.js
```

启动后访问 `http://127.0.0.1:8787/`。本机源文件通过 `node scripts/build-pages.js` 同步静态产物；界面、意见模块和规则引擎共用来源。此公共仓库只发布静态产物与说明，不包含本地后台、个人案件或 API Key。

> 本工具输出仅供法律风险分析参考，不构成正式法律意见。
